# S.O.S Ar Condicionado Automotivo

Site institucional desenvolvido para uma empresa real do segmento de climatização automotiva.

O projeto foi construído utilizando HTML5, CSS3 e JavaScript puro, com foco em responsividade, experiência do usuário, organização do código e identidade visual.


## Estrutura

```text
sos-site-azul/
├── index.html
├── assets/
│   ├── css/style.css
│   ├── js/config.js
│   ├── js/main.js
│   └── img/
│       ├── logo-sos.png
│       └── favicon.svg
└── README.md
```


## Funcionalidades

- Interface responsiva para desktop e dispositivos móveis.
- Animações de entrada utilizando IntersectionObserver.
- Menu de navegação interativo.
- Apresentação de serviços e do profissional responsável.
- Formulário de contato integrado ao WhatsApp.
- Código organizado com separação entre HTML, CSS e JavaScript.

## Tecnologias

HTML5 | CSS3 | JavaScript
